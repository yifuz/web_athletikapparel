## How to use
================================================================
- Each page's H1 must be the ONLY h1 on that page; section heads are h2/h3.
- `[CONTENT: user — ...]` markers are TODO notes for the user, NOT page copy.
  Keep them as editor-only placeholders (e.g. an HTML comment or an empty slot
  the user fills in later). NEVER render `[CONTENT: ...]` text on the live page.
  Same applies to `[IMAGE: ...]` — replace with a real image, never display the
  literal text.
- Give each page a unique <title> and meta description (keyword: "[category]
  manufacturer"). Example title: "Sportswear Manufacturer | Athletik Clothing".
- Reuse the same template/layout across all 7 for consistency.
- Replace every [IMAGE: ...] with real product/factory photos + descriptive alt
  text (e.g. alt="flatlock sportswear base layer").
- Cross-link via the "Related" lines for internal SEO. These MUST be rendered as
  real clickable links to the URLs shown in the markdown (e.g.
  [Underwear Manufacturer](/underwear-manufacturer/) → an <a href> link), not as
  plain text.
- Apply the 301s from docs/sitemap.md §8 when these go live.
