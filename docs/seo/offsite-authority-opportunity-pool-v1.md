## 4. 不做事项

- 不购买任何传递排名权重的链接、目录包或赞助位链接；
- 不为链接而建低质量档案；每个档案必须信息完整、真实、可维护；
- 不在未确认证书有效性的情况下追求认证名录收录；
- 不把平台付费推广（Alibaba 等）计入站外权威建设。
