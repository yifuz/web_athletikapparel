以下保留可复用的沟通方法与公司能力边界，仅在客户有相关需求时使用。具体供应商、型号、规格、采购数量和库存按项目核实。

| 项目 | 已确认内容 | 适用范围与条件 |
|---|---|---|
| 面料路线选择 | 客户有需要时，比较指定面料采购与定制替代方案，由客户选择 | 成本优势和性能接近作为开发目标沟通，具体差异由样品或测试确认，不保证完全复刻，也不虚构性能比例或具体价格。 |
| 库存与采购前提 | 区分可采购、有现货、可获得样布及需要开发；按当前项目确认采购时点和交期 | 不把某个面料曾经的库存或采购条件当成通用规则，不在可供性未确认前承诺直接寄样。 |
| 寄样安排 | 结合已确认的面料路线和预计订单数量讨论样品安排 | 需采购或开发材料时先确认条件，不把一般约两周的打样参考写成所有材料路线的交付保证。 |
| Laser perforation | 有激光打孔经验 | 按当前材料与图样评估具体要求，不将单次项目的可行性推广为任意材料和图样均可完成。 |
| bonded seam | 目前支持口袋、袖口等小部位的局部胶合 | 不承诺主拼缝或整件全胶合；需先区分客户要求胶合与 ACTIVESEAM 的具体位置。 |
| ACTIVESEAM | 有充分制造经验 | 根据客户希望使用的拼缝位置确认结构方案。 |

技术回复区分已确认能力、团队初判、开发目标和待验证结果；某项工艺可做，不等于全部性能已通过测试。具体材料规格、供应商身份或专利依据只在当前项目确有需要时核实。

## 询盘优先级与回复深度

所有者于 2026-10-28 授权根据客户与项目的匹配度、采购规模和持续合作潜力调整跟进优先级及回复深度。结合客户明确提供的预计数量与颜色拆分、产品与工厂能力匹配度、采购计划、复购证据和需求完整度判断；未知的信息保留为未知，后续有新信息时重新评估。

- 有较大或持续采购潜力且需求匹配的项目，可投入更深入的技术、面料与报价沟通。初期规模较小的项目可采用简短、友善的回复，先答复核心问题和标准商务条件，保留必要的项目评估空间。
- 所有者于 2026-10-29 补充：尚未提供任何技术资料的询盘，内部暂按低价值、低优先级跟进；礼貌回答核心问题并优先索取已有 tech pack，收到技术资料后结合其他信息重新评估。此分类用于分配跟进资源，不证明客户采购能力或长期价值，也不自动拒绝；不要在对客回复中使用低价值标签。其他信息不足的情况按实际信息判断。
- 询价的数量档位反映客户正在评估的近期采购量级，是判断项目优先级的重要信号；较小的档位可支持先按小单、较低优先级跟进。档位不等于已确认的实际订单量，也不足以单独确定长期采购能力或返单情况。客户的自述应标明为自述；Gmail 等邮箱类型不能单独证明其公司性质、专业程度、可信度或商业价值。
- 不因初步优先级判断自动承诺降低 MOQ、接受所有小单或预设客户会返单；按项目资料确认可行性、价格及交期。

## 首封回复策略

- 整体态度友善、亲切、专业；自然感谢对方来信，避免冷硬筛选或夸大能力。
- 保持简短，但逐项对照客户的主要问题。区分已回答、部分回答和待确认，不把“收到资料后回复”算成已给出具体答案。
- 根据客户的问题和沟通阶段，直接回答适用的 MOQ、样品及运输条件；客户未询问的打样费用和细节不必主动展开。需要说明打样费时，首次接触客户通常收费，金额按项目实际产生的费用核算，寄样运费包含其中；不虚构金额。以每款 500 件作为标准入口，避免不必要地强调客户的询价数量低于标准；客户询问每色条件或计划多色时说明通常每款每色 400–500 件、可混码，并按面料核算。对小单先了解需求，保留评估空间。
- 制样前先了解预计首单数量，对齐面料路线、起订要求与基本订单方案；具体孔径、间距、Logo 尺寸和定位、尺寸表细化等样品细节，待合作关系及基本订单方案确认后再展开，早期回复保持简短。
- 客户以面料采购门槛询问最低成衣数量时，说明面料采购条件与成衣生产条件分别需要满足，并简要解释定样、生产、QC 和运输成本；明确回复目前每款 500 件的标准。低于标准的数量仅保留项目评估空间，不自行承诺最低可接件数或例外报价。
- 定制项目未提供 tech pack 时，简短说明技术资料是准确评估与报价的重要前提，优先索取已有的 tech pack；在取得资料前不展开过多具体报价、生产或打样细节。参考图片可以辅助理解，但不保证足以准确报价；收到资料后再按项目需要确认其他信息。
- 对客户提出的特殊性能要求，先了解使用条件与 performance test criteria；取得可核验证据前不承诺达标。
- 推荐面料、可选颜色、单价、定制颜色或多色订单附加费，以及适用测试资料，均按项目资料评估后确认；不虚构现成测试结果或默认已具备全部性能。
- 对尚未确认的款式开发与生产可行性，明确需要审核资料，不把“愿意评估”写成已承诺承接。
- 未经所有者确认，不自行决定技术路线或设计方案；对结构、材料适配和工艺可行性先审核资料并与所有者对齐。面料推荐使用已确认选项，其是否适合具体需求仍需评估。
- 技术型询盘先回答面料路线、关键工艺与能力边界，并优先了解数量和颜色以评估项目；具体样品细节按上方阶段推进。客户尚未问及的其他地区运输、认证或报价不机械套入首封。
- 文案通过所有者验收不等于邮件已发送，也不构成未来自动发送授权。实际发送仍需当前对话中的明确指令。
