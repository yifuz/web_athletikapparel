不重复 SEO 或 GEO 的具体任务、观察日期和验收记录；SEO 与 GEO 分别在其独立工作流中执行。
它们产生的有效流量、询盘或品牌可见性结果，可以作为 Promotion 复盘输入，
但不在本表建立重复待办。

旧版 [`promotion-plan.md`](promotion-plan.md) 第 7 节记录的是网站推广启动阶段的原始 90 天安排，
不再作为当前执行日历。渠道定位、预算规则和单人内容基线仍分别以
[`promotion-plan.md`](promotion-plan.md) 和 [`promotion-matrix.md`](promotion-matrix.md) 为准。

## 2. 当前第一优先：P0

P0 不是立即优化广告，而是先恢复可靠的 Google Ads 当前事实。
现有 Google Ads 记录主要形成于 2026-08-05 上线阶段，不能代表 2026-09-24 的实际状态。
Google Ads 当前样本相对其他渠道更充足，并且可以通过 API 取得结构化数据，因此先集中分析；
其他渠道投入和结果样本不足，暂时只观察，不在 P0 消耗分析资源。

P0 需要形成以下四项输出：

1. Google Ads API 快照：使用明确的 Customer、账户时区、日期范围、Campaign 状态和 conversion action 口径。
2. 表现与结构数据：至少覆盖 Campaign / Ad group / keyword / search term 层级，以及地域、设备、impressions、clicks、CTR、平均 CPC、cost、conversions 和 cost per conversion。
3. 询盘质量对照：将 Google Ads / GA4 的 `generate_lead` 与 Fluent Forms 及人工记录核对，区分测试、垃圾、低于 MOQ、合格、报价、打样和成交，计算口径以人工确认结果为准。
4. 证据缺口清单：API 无权限、字段无法取得、conversion 定义不清或人工记录缺失时，标记 `unavailable` 或 `pending verification`，不写成 0。

2026-09-24 已完成平台侧只读审计，详见
[`Google Ads API 快照与流量质量审计`](ads/google-ads-api-snapshot-2026-09-24.md)。
当前 API 证据显示 Campaign 仅定向 United States，与 2026-08-05 上线时的
United States + Canada 历史记录不同；当前状态以本次 API 快照为准。所有者确认近一个月
没有实际表单提交，直接邮件询盘暂不记录 `mailto`。2026-09-24 已建立普通 163 邮箱的
本机只读询盘分析工具和[操作手册](ads/163-mail-inquiry-analysis-runbook.md)。完整
[邮件候选快照](ads/163-mail-inquiry-snapshot-2026-09-24.md)已自动发现并读取
`INBOX + Junk/Spam + Trash`，跨文件夹去重后最近窗口共 20 封邮件，其中 10 封询盘候选、
2 封 `needs_review`；Junk 包含 5 封候选，证明不能忽略。十封候选均没有明确自述来自 Google，
来源继续为 `unknown`；P0 等待人工确认真伪、MOQ 与销售阶段，尚未关闭。每日自动任务未启用。

Google Ads 会因隐私阈值省略部分低量搜索词；这些点击仍可能计入 Campaign 总数，
但不会出现在 `search_term_view`。因此搜索词明细不能被解释为全部搜索查询，
P0 应同时保留 Campaign 总量与搜索词可见覆盖差异。参考：
[Google Ads Help — About the search terms report](https://support.google.com/google-ads/answer/2472708?hl=en)。

Meta / Instagram、LinkedIn 和 YouTube 当前只保留账号及内容的正常运营，不要求在 P0
抓取访问、关注或转化快照，也不设优化结论。后续只有当样本足以支持同口径时间窗口比较时，
再为对应渠道建立单独分析节点。

P0 完成前：

- 不增加 Google Ads 预算。
- 不因单个点击率、浏览量、主页访问或普通表单数量宣布渠道有效。
- 不使用低样本的 Meta / Instagram、LinkedIn 或 YouTube 数据作扩量或暂停决定。
- 不启动新的付费渠道或再营销。
- 不启动 Outbound 发送。

## 3. 节点推进规则

- **日期是复盘点，不是自动通关条件。** 上一节点未达到完成门槛时，下一节点不得以日历到期为理由自动启动。
- **不同渠道使用各自 KPI。** Google 以合格询盘、搜索意图和 CPQL 为核心；Meta / Instagram 以真实关注增长、关注成本和品牌受众质量为核心；LinkedIn 与 YouTube 以专业触达、内容消费和可归因进站为核心。
- **询盘质量优先于平台转化数。** 扩量至少需要人工确认的合格 B2B 机会，不能只看平台报告的 conversion。
- **一次只改变一个主要变量。** 每次预算、地域、关键词、素材或受众调整都必须记录原因、开始日期和复盘日期。
- **未知不等于零。** 无法取得的数据标记为 `unavailable`；没有完成核对的数据标记为 `pending verification`。
- **单人产能优先。** 询盘回复与销售跟进优先于广告检查，广告与归因优先于基线内容，基线内容优先于 Outbound 和额外内容。

## 5. 状态词

- `待开始`：前置节点尚未完成。
- `进行中`：已经开始，并有可核验的执行记录。
- `观察中`：执行稳定，正在等待预先定义的数据窗口。
- `条件式待办`：只有明确门槛全部满足后才启动。
- `阻塞`：缺少权限、业务决策、合规条件或必要数据。
- `已完成`：完成门槛全部满足，并已记录下一步决定。
