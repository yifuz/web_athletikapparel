## 授权范围与实现

1. **详情页视频比例**：两款详情共用原生 `dialog` 播放器，横屏 16:9 完整显示原视频，不裁切、不重制媒体。缩略图和文字入口均在明确点击后打开并尝试播放，浏览器限制播放时仍可使用原生控件。照片区保持尺寸与选中照片；关闭、Escape 或点击背景均暂停视频并恢复原触发器焦点。无 JavaScript 时保留媒体直达链接，不支持 dialog 的浏览器退回视频直达。
2. **平板卡片**：展示库图片高度改为流式尺寸，768px 下由480px降至约261px；中等宽度减少正文内边距，卡片采用纵向伸展和底部 CTA 对齐。移动端单列与宽屏双列保留。
3. **手机阅读顺序**：详情页标题和简介仅输出一次，在窄屏按“标题简介 → 图集 → 特性、规格及询盘”排列；桌面仍为左图右文。保留全部原文、规格、链接、唯一 H1 和 URL。

未实施审查中的另外两条建议：材质筛选不变，首页 Showcase 入口内容与布局不变。没有更新产品数据、图片、视频、SEO 元数据或数据库。
