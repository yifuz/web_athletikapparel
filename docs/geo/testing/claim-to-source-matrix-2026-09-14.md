# GEO claim-to-source 证据矩阵（2026-09-14）

## 1. 目的

本矩阵把 Baseline v2 的六个核心采购与内容问题拆成可核验声明，回答三个问题：

1. 当前规范站是否已经公开支持该声明；
2. ChatGPT Search / Google AI Mode 实际采用了哪个来源；
3. 为了从“被引用”走向“被推荐”，还缺什么独立证据。

本文件不把历史站、品牌自有社交帖或其他供应商的自述升级为独立验证。`ISO 607` 不是标准编号；607 是 ISO 4915 分类下的 stitch type。ACTIVESEAM 是 Merrow 的命名技术，不作为普通 FLATLOCK 的同义词。

## 2. 证据等级

| 等级 | 定义 | 可支持的结论 |
|---|---|---|
| A — 规范第一方 | `athletikapparel.com` 当前公开、可索引页面及真实生产媒体 | Athletik 当前公开的定位、产品、设备、流程、MOQ 和技术说明 |
| B — 可控但非规范 | Athletik LinkedIn / Instagram 及所有者确认的历史或矩阵站 | 可证明该渠道公开过相关声明；不能替代规范站，也不算独立背书 |
| C — 独立一手 | 设备商、标准机构、认证机构、展会或政府/行业组织的直接页面 | 可支持技术定义、证书状态、实体存在或经编辑核实的案例 |
| D — 第三方二手 | 目录、媒体、行业博客、B2B 平台 | 只按其实际核验范围使用；平台 `Verified` 不等于设备、质量或订单表现获验证 |
