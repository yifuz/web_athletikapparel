## 6. 改动门槛

满足以下至少一项，才把观察升级为网站改动：

1. 同一模式在两个以上固定 Prompt 中出现；
2. 同一模式被两个产品采用；
3. 同一模式连续两个月复现；
4. 单次结果揭示了明确事实冲突、抓取阻断或规范来源错误；
5. 改动能补充真实第一方生产证据，并且不会制造重复页面、关键词堆叠或未经证实的声明。

以下情况不触发网站改动：单次排名波动、Sources 面板未完整保存、个性化会话、竞品自建榜单中的营销措辞、没有 Athletik 证据支持的数字或性能承诺。
