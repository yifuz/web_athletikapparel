# 选题核查：功能针织面料测试选型指南（2026-11-17）

状态：`opportunity-reviewed / owner-direction-pending`。本文件是选题与证据边界，不是已批准正文、已创建页面或上线任务。

## 为什么优先考虑

所有者提供并接受的 [V2-C08 手动样本](valid-retest/manual-2026-11-16/README.md#v2-c08-回答与来源)在评估技术针织 OEM 时讨论了弹性、胀破、起球、色牢度与尺寸变化等测试，并引用或列出标准来源。样本说明这类信息与采购尽调问题相关，不证明标准条目是该次答案选择来源的唯一原因，也不保证新内容会获得引用。

现有 [Garment Quality Control Checklist](https://www.athletikapparel.com/garment-quality-control-checklist/)覆盖生产阶段、检验与测试的区别，并列出面料性能项目；[Tech Pack Guide](https://www.athletikapparel.com/technical-knitwear-tech-pack-guide/)说明如何记录要求，已给出低弹力针织物的一项 ASTM 方法示例。[OEM Evaluation Guide](https://www.athletikapparel.com/evaluate-technical-knitwear-oem/)则说明如何审核报告和实验室范围。

可进一步回答、但目前未集中展开的问题是：**针对不同针织面料与服装用途，如何选择测试目标、理解方法适用范围，并判断一份报告是否与实际项目匹配。** 建议评估为一篇有独立采购意图的技术指南，并从既有三篇文章建立合理衔接；页面位置、URL、标题和正式正文尚未批准，不在本轮修改。

## 可供起草时再次核验的标准来源

以下是 2026-11-17 对标准发布方公开摘要的核查，不复制标准正文，不从标准编号推断适用于所有材料或项目。

| 买家问题 | 发布方公开资料 | 使用边界 |
|---|---|---|
| 面料弹性如何测量 | [ISO 20932-1:2018](https://www.iso.org/standard/69489.html)：采用织物条样测试弹性；有 2021 修订件。 | 标准范围排除窄幅织物；面料伸长数据不直接等同成衣压缩压力。需按产品、方法与修订件确认。 |
| 面料胀破强力如何判断 | [ISO 13938-2:2019](https://www.iso.org/standard/74896.html)：气压法测定织物胀破性能，ISO 显示 2025 年复核确认。 | 指向织物测试，不等同接缝强力、弹性恢复或所有产品的验收阈值。 |
| 起球或起毛如何测量 | [ISO 12945-2:2020](https://www.iso.org/standard/75375.html)：改良 Martindale 方法；页面当次显示已发布且处于复核阶段。 | 方法和项目阈值需分别确认，不把一个级别作为所有面料统一标准。 |
| 洗后尺寸变化如何核对 | [ISO 6330:2021](https://www.iso.org/standard/75934.html)规定家用洗涤和干燥程序；[ISO 5077:2007](https://www.iso.org/standard/41877.html)涉及洗涤干燥后尺寸变化的测定。 | 洗涤程序与尺寸变化测定的作用不同；具体洗涤、干燥条件和验收值按项目约定。 |
| 耐洗色牢度如何核对 | [ISO 105-C06:2010](https://www.iso.org/standard/51276.html)：家用和商业洗涤色牢度；ISO 显示 2026 年复核确认。 | 方法选择、测试条件与项目接受标准需核实，不推断已有任何面料测试通过。 |

## 推荐交付范围

若所有者批准，先完成一份可审核的英文指南草稿，包含：测试目标与适用对象对照、报告需核对的面料 / 批次 / 色号 / 方法版本 / 条件 / 结果字段、如何结合项目设定验收值，以及明确标注为示意的填写示例。再评估与现有 QC、Tech Pack 和 OEM Evaluation 文章的衔接、SEO 页面所有权和可发布的结构。

不需要实物样本即可完成标准与报告阅读指南；但示意内容不能伪装成公司真实实验报告，不编造测试结果、统一合格阈值、认证或实验室资质。真实批次测试应以适用的完整现行标准、买家要求和实验室实际报告为准。
