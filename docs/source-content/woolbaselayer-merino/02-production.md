# Production

The Production page on the source site is an image gallery documenting the full merino wool garment manufacturing workflow. There is no body copy beyond the heading - the process is shown through the photo gallery below.

**Captured workflow stages** (inferred from image filenames, ordered by production sequence):

1. **Fabric inspection** - incoming merino wool fabric QC
2. **Fabric cutting** - manual and automated cutting rooms
3. **Sample production** - pre-bulk sampling
4. **Sewing** - flatlock + active seam construction
5. **Inline inspection** - QC during sewing
6. **Measuring** - dimension verification
7. **Needle detection** - broken-needle safety scanning
8. **Lab testing** - pilling, color fastness, shrinkage, stability, fabric weight, button, color matching
9. **Ironing / pressing** - finishing
10. **Packing** - final packaging
11. **Ready product warehouse** - finished goods storage
