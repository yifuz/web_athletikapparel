## Redirect quirks to be aware of

The site uses long SEO-optimized slugs internally, with short "pretty"
slugs that 301-redirect to them. Two short slugs behave unexpectedly:

- **`/equipment.html`** 301-redirects to the **home page** (not to the
  real Equipment page). The real Equipment page lives at the long slug
  shown in the table above.
- **`/photo-gallery.html`** 301-redirects to the long slug with the
  typo `apparl` (not `apparel`). That long slug returned HTTP 403 to
  our non-browser fetcher, so the Photo Gallery page content was not
  directly captured - see `03-photo-gallery.md` for the placeholder
  and how to re-fetch it.

## Filename conventions used

- All image filenames were **slug-cleaned**: lowercased, non-ASCII chars
  (the source used Chinese `副本` = "copy" suffixes on many files) stripped
  to dashes, size suffixes (`-1024x768`, `-scaled`) removed so each file
  is the **full-resolution original**.
- Resulting names are descriptive: `audit-9-higg-200.png`,
  `1-yamato-sewing-machine.jpg`, `merino-wool-base-layer-13-.png`
  (the trailing dash is the artifact of stripping `副本`).

## Generation
