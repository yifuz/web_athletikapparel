## Filename conventions used

- All image filenames **slug-cleaned**: lowercased, size suffixes removed
  (`-150x150`, `-300x200`), so each file is the **full-resolution original**.
- Examples: `fiber-2-coolmax.jpg`, `testing-4-sgs-s.jpg`,
  `10-bcg-x.jpg` (brand-partner logos retain their leading index number
  from the source filenames so they sort in source order).

## Generation

The `.md` files in this folder were generated by `gen-pages.py` (also in
this folder) from the captured image manifest `.image-manifest.json`
plus the body-copy text. Re-run `python gen-pages.py` to regenerate.
