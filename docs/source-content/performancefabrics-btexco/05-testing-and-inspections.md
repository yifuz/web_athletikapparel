# Testing and Inspections

Fabric tests will be done in **BV, SGS or ITS** etc. before shipment.

Inspection will be conducted according to the international **Four Point System** by the QC/QA Team consisting of six QC/QA staff:

- Linda Ding - QC/QA Manager
- Deputy QC/QA Manager
- QC (4 staff)
